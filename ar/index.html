04 / تقنيات مرتبطة بمشاريع فعلية

التقنيات التي أشحن بها أنظمة إنتاجية

الخلفية والمعمارية

  • Laravel / PHP 8+

    منصات SaaS، ماجيك لينكر، محطات الوقود، حاوياتي

  • Stancl/Tenancy

    توجيه النطاقات الفرعية وعزل قواعد البيانات

  • Node.js & WebSockets

    مراسلة IFAF اللحظية وإشارات WebRTC

  • Python

    تشغيل نماذج Qwen المحلية وأتمتة التحليل

الواجهات والموبايل

  • React.js / Next.js

    التوأم الرقمي لحاوياتي، لوحات التحكم، المنصات التعليمية

  • React Native (Expo)

    تطبيقات ماجيك لينك، عائلة السريع، البصيرة، البصمة

  • Three.js / WebGL

    التوأم ثلاثي الأبعاد لساحة الحاويات ومختبر 3D

  • TypeScript & Tailwind

    واجهات صارمة الأنواع ودعم كامل للغة العربية RTL

هندسة الذكاء الاصطناعي

  • Self-Hosted LLMs (Qwen)

    نقل محرك منصة عبدالعزيز لتقليل التكلفة والزمن

  • Autonomous AI Agents

    وكيل التفاوض الآلي في السوق الإلكتروني AI

  • OpenAI & Prompt Pipelines

    SIOSS، معلم الحروف الذكي، وتحليل الأسواق

البيانات والدفع والبنية التحتية

  • MySQL, PostgreSQL, Redis

    دفاتر حسابات ذرية، فهارس مركبة (-30% زمن استجابة)، طوابير

  • Stripe, PayPal, Moyasar

    دفع متعدد العملات وتسوية عمولات التجار

  • Docker, AWS, GitHub Actions

    خوادم Linux، خطوط CI/CD، وحاويات Docker

06 / أسلوب العمل الهندسي

مبادئ ألتزم بها في كل نظام

01

سلامة البيانات قبل اللمسات الشكلية

حدود عزل المستأجرين، المعاملات المالية الذرية، وـ webhooks الدفع المقاومة للتكرار تُصمَّم أولاً. الواجهة الجميلة فوق قاعدة بيانات هشة تنهار عند أول ضغط حقيقي.

02

من مخطط SQL وخدمات Laravel/Node وحتى رفع التطبيق على Google Play وإعداد خوادم Linux وDocker — مهندس واحد مسؤول بدلاً من ضياع التفاصيل بين الفرق.
